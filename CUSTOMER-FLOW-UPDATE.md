# Customer flow update

Based on the seven customer transaction/account prototype screens in Pawfee Shop (1).zip. The existing cream storefront background, PHP front controller, database and admin/Brevo integration are retained. The replacement introduces My Account overview and management screens, separate My Orders and Returns routes, redesigned checkout/cart and order confirmation/tracking. Card and wallet choices are simulations using the existing mock payment method. No new database schema is required. Order history filters use actual order data; delivery estimates and privacy/deletion controls shown in the prototype are not implemented. Existing Philippine address fields and peso currency are retained.

Before replacing files, back up the project, database, uploads, includes/mail.local.php and vendor directory. Copy the updated files into the existing project (do not overwrite credentials or delete images). Run composer install if vendor is missing. No SQL reimport is needed. Existing legacy duplicate carts are not consolidated automatically; the newest cart belonging to the account is selected. Test two accounts on the same browser, guest-to-account cart merge, checkout with COD/pickup/mock payment, order confirmation, history, tracking, cancellation/return requests, and Brevo delivery. PHP syntax checked; live database/browser testing not performed.

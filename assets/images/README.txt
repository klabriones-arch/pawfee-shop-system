HOW TO REPLACE IMAGES (no code changes needed)
==============================================
Just drop a file with the right name into the right folder. Missing files automatically show placeholder.svg.

Logo ............ assets/images/logo.png      (or .jpg / .svg)   <- replaces logo.svg
Hero banner ..... assets/images/hero.jpg       (or .png / .webp)
Categories ...... assets/images/categories/<category-slug>.jpg
                  e.g. coffee-coolers.jpg, tea-matcha.jpg, fresh-bakes.jpg, sandwiches.jpg, desserts.jpg, merchandise.jpg
Products ........ assets/images/products/<product-slug>.jpg
                  e.g. pawfee-latte.jpg, purrfect-choc-chip-cookie.jpg, caramel-cold-brew.jpg
                  Extra gallery photos: pawfee-latte-2.jpg, pawfee-latte-3.jpg, pawfee-latte-4.jpg
Supported: jpg, jpeg, png, webp (svg also works).

Images uploaded in Admin > Products are stored in /uploads/products and take priority over these files.
